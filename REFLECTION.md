Reflection

What was hardest?
The hardest part was getting the AI to work once the app was deployed on Vercel. I first built the AI part for the Anthropic API, but that needs payment to get a key, so I had to switch to Google Gemini and change my code. At first I pushed the old code to GitHub, so Vercel deployed the old version and my Gemini key did nothing. After that, the errors came one after another: a 404 because the model name was wrong, then a 503 because Google was busy, then a 504 timeout because the request took too long. I fixed these one at a time by reading the error in the browser's Network tab, adding a second fallback model, and allowing more time.

The terminal was also hard for me. I did not always understand the commands, and I was confused about where the project was stored, in Downloads or on the Desktop (my Desktop is inside OneDrive). Once, a test clone went into my real project folder by mistake, and I had to find it and delete it.
